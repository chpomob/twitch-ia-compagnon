**Findings.**

**B1 — BLOCKER — failed supervision writes produce a false healthy state (R6, AC19).** At `core/config_ui/__init__.py:3880–3890`, `_record_supervision` catches `OSError` and continues without invalidating the old record. After a successful initial `not_started` publication, a later `launched` write can fail and leave `not_started` readable. Health at :7637–7648 then returns `idle: not started`, exit 0, even though this UI launched a runtime that has exited. This is a failure of the required supervision transition, not an operator Stop.

Reproduction C6 uses a real image/container/volume and no patched production code: complete the silent wizard using the trial's production dry-run proof; restart a UI with automatic startup off; change `/data/twitch-ia-compagnon` to mode `0500`; exchange the access token for a session and POST `/start` with the real CSRF token/Origin. The process is launched, cannot write its feed and exits. Its supervision write also fails. The resulting evidence is:

```text
authenticated Start: {"http_status": 200, "supervision_state": "not_started"}
after launched runtime exits: 'idle: not started' exit 0
live runtime processes: []
failed supervision write logged: True
runtime failure logged: the supervision record could not be written (launched)
error: feed: could not be written
```

Make publication/transition failure fail closed, so it cannot be mistaken for intentional idle. A regression check needs to drive the producer's real failed-write path and then the consumer; merely adding another already-correct fake health document will not cover it.

**B2 — BLOCKER — AC11 was changed in the test, not met or amended in the specification (R3, AC11, test policy).** `Dockerfile:28` adds a third `FROM scratch` stage to remove inherited `GPG_KEY` metadata. That has a clear technical rationale and C5 finds no baked credentials, but R3/AC11 still require two stages and a final pinned Python FROM (`spec.md:158–165`, :345–347). The `bedae98` diff replaces `assert len(stages) == 2` and the final-image pin check with `== 3`, a pin check on the intermediate runtime stage, and `final_from == "scratch"` (`tests/test_container.py:2168–2181`). The test now passes for a different contract while retaining its AC11 name.

The P12F2 build transcript itself says AC11 needs the operator's amendment; none is in the normative spec. A closing reviewer cannot supply that amendment implicitly.
